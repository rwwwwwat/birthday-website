# 第三阶段范围与决策

- 原始图片和需求文档保持原样，照片允许公开访问。
- 原生 JavaScript 五场景，统一内存状态；静态站点无前端路由回源需求。
- 不接入未经确认的音乐、不推断恋爱日期或生日；照片说明暂为占位。
- API 存活检查不等于数据库就绪；所有数据库写入均未实现。
- 愿望发送按钮禁用，接口返回 503；管理员接口拒绝访问。
- 独立管理页面、管理员认证、数据库驱动和完整业务在后续阶段实现。
- 没有 GitHub 远程、推送、Cloudflare 配置或可执行发布工作流。

## SQL 审查要点

`001_create_database_and_wishes.sql` 仅供审阅，不由应用启动执行。
使用 `DB_ID`、`OBJECT_ID`、`sys.indexes` 跳过已存在对象，建库通过独立动态批次执行。
表与索引在事务中创建；异常回滚并抛出。缺失预期字段时抛错，不改造既有表。
Content/Source 为非空 Unicode 字段，并排除常见空格、制表和换行组成的空内容；
更完整的 Unicode 空白检查需由未来 API 实现。时间默认 SYSUTCDATETIME()；
DATETIME2 本身无时区标记，未来写入必须统一 UTC。应用不得允许客户端指定 Source、
CreatedAt 或 IsRead。需要用户确认后才能执行数据库修改。
